# MyCV - online CV

A responsive portfolio and online CV built with plain HTML and CSS.

## Live site

https://andisiwememela102-ux.github.io/MyCV/

## Included sections

- Short personal introduction
- Skills developed through project work
- Independent software project experience
- Current software engineering studies
- Public GitHub profile link

Personal contact details and unprovided employment or qualification claims are intentionally omitted. Add accurate information you choose to share before expanding the CV.

## Run locally

Open `index.html` in a browser. No build step or server is required.

## Deploy

The public repository publishes the root `index.html` and `styles.css` through GitHub Pages from `main`.
